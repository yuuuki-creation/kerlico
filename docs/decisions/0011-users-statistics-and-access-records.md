# 0011 多用户、流量带宽与访问记录

- **状态**：已确认（管理账户、节点成员映射、唯一业务计量与内存态访问记录已合入主工作树；持久化存储与带宽历史采样待实现）
- **日期**：2026-11-02

## 背景与确认需求

用户明确以下多用户管理与统计记录要求，并指定参考 Xray-core 的日志与统计能力（固定源码对照见 [Xray 统计与访问记录研究](../../reference/research_notes/xray-statistics-and-access.md)）：

1. **单节点多用户管理**：单个节点支持配置多个独立用户，每个用户具备独立用户名与管理密码，用户名默认附带 UUID 后缀确保唯一性。
2. **流量与带宽统计**：按用户记录上传/下载累计流量，以及当前速率、平均速率与采样峰值带宽，同时支持按节点、命名出站与 `Engine` 汇总查看。
3. **访问记录（元数据）**：保存用户访问的目标域名/IP、端口、网络协议、观测来源地址、所选出站、阶段状态、时间与流量明细，不记录业务载荷或明文认证秘密。

## 决定与架构设计

1. **管理身份与协议原生凭据分离**：
   - 根配置 `accounts` 维护持久管理 `UserId`、唯一用户名与 Argon2id 密码摘要；
   - 节点 `members` 将 `user_id` 映射到各协议实际的 `native_credential`，不修改协议线格式，也不允许跨节点复用协议秘密。
2. **唯一业务计量边界与四维投影**：
   - 入站完成真实鉴别后签发绑定 `UserId` 与 `NodeId` 的 `PeerSession`；
   - 共享 `Dispatcher` 在返回的逻辑业务通道（`TcpFlow`、`FixedUdpFlow`、`UdpAssociation`）处封装一次计量，确认的业务字节增量同时投射至 `Engine`、用户、节点与命名出站四个视图；
   - 底层载体开销（`CarrierUsage`）独立统计，不混入用户业务流量。
3. **结构化访问记录与远端未知 IP 边界**：
   - 每条逻辑流或 UDP 关联生成唯一的 `FlowRecord`，区分入站原始请求目标（`OriginalTarget`）与实际目标绑定（`TargetBind`）；
   - 当远端代理自行解析目标网站时，`TargetBind` 保持 `Unknown`，不为填写日志而在本机额外解析远端网站域名。
4. **持久化与查询重置语义**：
   - 用量汇总、带宽采样时间桶与访问记录设计为异步批量持久化存储；
   - 查询重置仅更新调用方的观测窗口基线，不删除已持久化的历史数据。详细设计见 [多用户、用量统计与访问记录](../statistics-and-users.md)。

## 落地状态

- **已实现**：`AccountSpec` 与 `kerlico account-new` 命令、节点 `members` 与 `CredentialManifest` 隔离校验、`Dispatcher` 唯一业务计量与有界内存态 `Telemetry`（`usage()` 四维投影与 `records()` 访问记录查询，见 [核心接口](../interfaces/core.md)）。
