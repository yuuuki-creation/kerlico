## 记录规范与状态定义

每份决策文档包含：**编号与状态**、**背景与约束**、**备选方案**、**决定与理由**、**架构影响**、**上游/标准依据**及**验证目标**。

| 状态标签 | 含义 |
| --- | --- |
| `草案` | 候选方案，尚待讨论确认 |
| `已确认` | 用户明确确认的架构原则或需求边界 |
| `已采用` | 在授权任务范围内落地的具体工程方案 |
| `已取代` | 被后续决策替代，保留历史演进脉络并链接新记录 |
