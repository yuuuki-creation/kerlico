## 阅读约定

“契约”表示建议实现必须满足的行为；英文名称用于讨论概念，不是已经存在的 Rust 类型或最终公开 API。目录树与文件路径标为未来规划时，不表示文件已创建。参数需要有明确的限制，但本轮不随意指定容量、超时或性能数字。

目标设计与当前接口分开维护。用户逐项确认和任务内授权自主采用分别记录，不混用状态；实际 crate 版本以 Cargo.lock 为准，不从 Go 项目的依赖表推定。
