# 1.11.0 发行说明

完成 `M8`–`M10`（`v1.11.0`）Mihomo 原生配置直通、多协议分享链接订阅解析、TUN 自动路由守卫、双栈 UDP/TCP DNS 劫持、本机进程路径匹配及 Hysteria2 / TUIC 动态端口跳跃深度对齐。

## 新增与增强

- **Mihomo YAML 原生直通、`proxy-providers` 覆写与全协议 URI 分享链接解析（`M8`）**：支持直接加载顶层 `port`（`http-port`）、`socks-port`、`mixed-port`、`allow-lan`、`bind-address`、`mode`、`rules`（含 `DOMAIN*`、`GEOSITE`、`GEOIP`、`IP-CIDR*`、`SRC-IP-CIDR`、`DST-PORT`、`SRC-PORT`、`IN-PORT`、`IN-TYPE`、`IN-NAME`、`IN-USER`、`PROCESS-NAME*`、`PROCESS-PATH*`、`RULE-SET`、`NETWORK`、`UID`、`DSCP`、`SUB-RULE`、`AND`/`OR`/`NOT`、`MATCH`/`FINAL`）与 `sub-rules` 子规则表；自动注入 `DIRECT`、`REJECT`、`REJECT-DROP`、`PASS` 内置出站；`proxy-providers` 支持 `override`（`additional-prefix`、`additional-suffix`、`skip-cert-verify`、`udp`、`dialer-proxy`）与 `vmess://`（v2rayN Base64 JSON）、`ss://`（SIP002 与 Legacy Base64）、`ssr://`、`vless://`、`trojan://`、`hysteria2://`/`hy2://`、`tuic://`、`anytls://`、`wireguard://`/`wg://`、`socks5://`、`http://` 分享链接解析。
- **用户态 TUN 自动路由守卫、UDP/TCP DNS 劫持与跨平台本机进程查询（`M9`）**：`TunRoutePlan` 新增跨平台系统路由安装与 `Drop` 自动回滚守卫 `TunRouteGuard`，支持 `route-address-set` 与 `route-exclude-address-set` 从规则集展开网段；TUN 配置 `dns-hijack` 或 `dns-mode: hijack` 时自动注入端口 53 的 `hijack-dns` 规则，且 `Dispatcher` 同时支持多目标 UDP 会话 DNS 劫持与 RFC 1035 2 字节长度前缀 TCP DNS 劫持；新增 `crates/egress/src/process.rs` 跨平台本机套接字进程解析（Linux `/proc/net/{tcp,udp}*` + `/proc/<pid>/fd`、macOS `lsof`、Windows `GetExtendedTcpTable`/`GetExtendedUdpTable`），驱动 `PROCESS-NAME`、`PROCESS-PATH`、`PROCESS-NAME-REGEX`、`PROCESS-PATH-REGEX` 实时匹配。
- **Hysteria2 / TUIC 动态 UDP 端口跳跃与 `SUB-RULE` 递归求值（`M10`）**：`crates/protocol-tuic` 新增 `HoppingSocket` 抽象 UDP 套接字，支持 `ports` / `server_ports` / `mport` 端口区间列表与 `hop_interval` / `hop_interval_ms` / `hop_interval_max` 定时动态轮换本机源端口而不中断 QUIC 连接；`crates/protocol-hysteria2` 新增毫秒级 `hop_interval_ms` / `"ms"` 后缀与 `mport` 别名；`RouteTable` 支持 `SUB-RULE` 命名子规则表递归匹配。

## English

Completes stages `M8`–`M10` (`v1.11.0`) for native Mihomo YAML drop-in compatibility, multi-protocol share-link subscription parsing, TUN route guard automation, UDP/TCP DNS hijacking, cross-platform local socket process matching, and Hysteria2 / TUIC dynamic UDP port hopping.

- **Native Mihomo YAML drop-in, `proxy-providers` overrides, and multi-protocol URI share-link parser (`M8`).** Supports top-level `port` (`http-port`), `socks-port`, `mixed-port`, `allow-lan`, `bind-address`, `mode`, `rules` (including `DOMAIN*`, `GEOSITE`, `GEOIP`, `IP-CIDR*`, `SRC-IP-CIDR`, `DST-PORT`, `SRC-PORT`, `IN-PORT`, `IN-TYPE`, `IN-NAME`, `IN-USER`, `PROCESS-NAME*`, `PROCESS-PATH*`, `RULE-SET`, `NETWORK`, `UID`, `DSCP`, `SUB-RULE`, `AND`/`OR`/`NOT`, `MATCH`/`FINAL`), and `sub-rules`; automatically injects built-in `DIRECT`, `REJECT`, `REJECT-DROP`, and `PASS` outbounds; adds `override` (`additional-prefix`, `additional-suffix`, `skip-cert-verify`, `udp`, `dialer-proxy`) and `vmess://`, `ss://`, `ssr://`, `vless://`, `trojan://`, `hysteria2://`/`hy2://`, `tuic://`, `anytls://`, `wireguard://`/`wg://`, `socks5://`, and `http://` share-link parsing.
- **Userspace TUN route guard, UDP/TCP DNS hijack, and cross-platform local process lookup (`M9`).** Adds `TunRouteGuard` for automatic route setup and teardown on drop plus `route-address-set` / `route-exclude-address-set` CIDR expansion; automatically injects port-53 `hijack-dns` rules when TUN enables `dns-hijack` or `dns-mode: hijack`, handling both multi-target UDP associations and RFC 1035 TCP DNS queries; resolves local socket owners across Linux, macOS, and Windows for `PROCESS-NAME*` and `PROCESS-PATH*` rules.
- **Hysteria2 / TUIC dynamic UDP port hopping and `SUB-RULE` evaluation (`M10`).** Adds `HoppingSocket` to `crates/protocol-tuic` (`ports` / `server_ports` / `mport`, `hop_interval` / `hop_interval_ms` / `hop_interval_max`) for seamless QUIC source/destination port rotation, millisecond hop intervals and `mport` aliases for Hysteria2, and recursive `SUB-RULE` evaluation in `RouteTable`.
