## 配置、CLI与Rust API审阅

- 当前JSON根必填version/outbounds/inbounds；nodes/local_inbounds/limits可选。外层及主要协议Options使用deny_unknown_fields，各模块仍须在最终矩阵覆盖嵌套对象、枚举分支、拼错字段、非对象值、字段互斥及过界值；HTTP headers等明确开放的映射不是任意顶层配置字段。
- 接入标签由固定转发/nodes/local_inbounds共同去重，出站另有命名空间；无认证本地动态代理只有工厂明确允许且回环监听才可进local_inbounds，不能用隔离秘密充当nodes鉴权。
- 两类凭据集合：scoped鉴权集合决定nodes资格，额外isolation集合只参与与鉴权并集的查重；空isolation不能隐藏真实认证。包装保留原内层域；HTTP/Naive/TT实际Basic重叠、SS/SS2022包装、SSR弱/无认证组合、Sudoku none及Mieru原UDP都应有明确配置反例。
- AccessService/Egress仍是统一目标入口；当前对域名做系统解析及IPv4优先。没有Tor或匿名远端DNS能力，不在本轮为新协议改变该契约。字面IP、接入族、载体族、网站族分别处理。
- ConnectContext.run每调用独立相对预算，不自动扣除其他run耗时。Egress候选阶段维护总截止时间，其他协议的建立/响应完成程度分别记录；check不证明网站可达或认证已被远端确认。
- CLI只有modules/check/run及clap通用help/version；check可读取证书/私钥及做密钥派生，但不监听拨号。单会话失败只累加计数的场景不导致进程失败，退出0不是业务全部成功；没有热重载、JSON管理API或TUN承诺。
- core公开面含Address/Destination、Error/Result、I/O别名、Capabilities、ConnectContext、StreamConnector、两种UDP通道、AccessService、InboundContext/Protocol、凭据分域和预算/观察接口。配置工厂、Engine绑定/运行/统计及协议直接构造器也在pub范围：SS/SS2022注入构造、Hysteria2 from_options/serve_udp、Naive build_with_connector等不能只在源码出现而遗漏其限制。
- IoStream仅Send+Unpin等，不要求Sync；Rust trait与BoxFuture不构成稳定C ABI或动态插件接口。若发布外部Rust API，独立调用者必须经真实Egress与Engine装配，避免仅构造对象便称端到端功能。

## 匿名发布事实与门槛

只读Git元数据确认：实际author/committer为固定Anonymous，commit/tag签名配置均禁用，hooksPath为.githooks；origin符合用户指定公开目标；.private被忽略且无跟踪文件。现有6个可达提交未见非匿名作者/提交者或签名状态。**没有运行完整内容钩子、全历史敏感数据扫描或产物扫描，不能声称匿名发布检查全部通过。**

后续必须按实际暂存树/可达历史检查所有拟发布提交与标签，不能仅看工作树或最后commit。保留合法第三方通知；`.private`、私钥、未知二进制仍拒绝，不关闭/跳过钩子。正式资产另查调试路径、构建用户名/主机、日志、配置、环境元数据与内置真实凭据；Git匿名字段不保证平台账号/网络记录匿名。构建源码路径重映射和去调试信息必须作用于最终产物，不能用历史debug CLI摘要充作发行匿名证据。
