# 1.0.0发行说明

本版按用户要求先发布源码，再继续海外构建、测试和修复。版本号不代表当前整树通过验收。首次发布提供源码，暂不附带旧快照二进制；后续产物须对应本标签，修复产生源码变化时发布新补丁版本，不改写已发布标签。

本快照整合原21协议模块、新编写的Tor与WireGuard、共享命名出站、多用户身份和运行业务账本，自有代码采用GPL-3.0-only。Tor仅TCP出站；WireGuard双角色首轮未经编译、格式、测试或真实对端验证。

发行前开发输入的部分结果为H3库260通过、四个H3消费模块161通过、核心/出站/Engine93通过。它们来自不同冻结输入，不能相加宣称本标签整树通过。最新开发CLI的SSR-Mihomo为191/192，剩一项IPv6的auth_aes128_md5 + random_head TCP失败。TrustTunnel-Mihomo为258通过、54项参考限制、4项未测，无失败；不能将316条全部称通过。详见[恢复记录](../testing/protocol-restoration-20261102.md)。

当前仍缺自动WARP部署、持久流量与访问历史、带宽历史、完整CLI多语言，以及OpenVPN、OpenConnect、EasyTier、Tailscale、ZeroTier、MASQUE。共享新架构、Tor、WireGuard及同一整树的验收继续在发布后进行。旧配置例未全部迁移到版本2，先阅读接口文档并从local-forward-v2.json开始。

根LICENSE适用于自有代码，第三方材料保留原版权与许可证。项目Git身份匿名，私有机器资料和凭据不随源码发布。

## English

This is a source-first release published before further testing at the user's explicit request. It is not a fully validated release. Initial publication provides source only. Binaries must match this tag; source fixes require a new patch version rather than rewriting the tag.

The snapshot includes 23 protocol modules, a shared outbound dispatcher, user identities, and an in-memory business usage ledger. Tor TCP outbound and WireGuard client/server code are newly written. WireGuard has not been compiled or tested. Earlier passing tests belong to their individually recorded development inputs and do not validate this release tree.

Known gaps include one SSR interoperability failure, automatic WARP provisioning, durable usage/access and bandwidth history, complete CLI localization, and six additional tunnel/overlay endpoints. Builds, tests and fixes follow publication. Original code uses GPL-3.0-only; third-party licenses remain intact.
