# 1.0.0 发行说明

`v1.0.0` 为按“先发布源码、再执行整树编译测试”策略发布的**源码先行版本**（标签 `v1.0.0`，提交 `57f036c646d85ff71d78ba10aca8af52d1b7326c`）。当前 Release 仅提供源码，二进制产物将在海外 worker 对应构建与测试完成后补充；后续源码修复将通过新补丁版本发布，不改写已发布的 `v1.0.0` 标签。

## 本版包含内容

- **23 个协议模块**：涵盖原 21 个协议模块（VLESS、VMess、Trojan、Shadowsocks、SS2022、SSR、AnyTLS、ShadowTLS、Snell、TUIC、Hysteria v1/v2、ShadowQUIC、Mieru、Naive、TrustTunnel、Sudoku、SOCKS、HTTP、SSH、Gost Relay）以及新编写的原生 `protocol-tor`（TCP 出站）与 `protocol-wireguard`（双端 TCP/UDP）。
- **全局共享出站与配置 v2**：实现唯一共享出站调度器（`EgressRuntime` / `Dispatcher`）、节点地址族模式（`ipv4-only` / `ipv6-only` / `dual-stack`）、远端代理原目标透传、管理账户（`AccountSpec`）与内存态业务计量账本（`Telemetry`）。配置升级为 JSON v2（见 [配置 v2 迁移指南](../config-v2-migration.md) 与 `examples/config-v2-minimal.json`）。
- **近期局部验证进展**：核心/出站/Engine 局部测试（14 程序 93 项）、H3 库（260 项）及 4 个 H3 消费模块（19 程序 161 项）已通过；ShadowTLS sing-box 矩阵 108/108 通过；TrustTunnel Mihomo 矩阵 258 通过、54 参考端限制、4 未测、0 失败；SSR Mihomo 矩阵 191/192 通过（详见 [恢复记录](../testing/protocol-restoration-20261102.md)）。

## 已知边界与待完成项

- **待编译/复验范围**：`v1.0.0` 同一整树的 `check`、`release` 构建与 `all-targets` 测试正在海外 worker 执行；`protocol-wireguard` 首轮代码尚未经过编译与测试；SSR 剩 1 项 IPv6 `auth_aes128_md5 + random_head` TCP 互通失败；Sudoku 官方矩阵仍有 18 项失败待修。
- **待实现功能**：双栈缺族时的设备级 CF WARP 自动部署、流量/带宽/访问记录持久化存储、完整 CLI 中英双语本地化，以及 6 个后续端点（OpenVPN、OpenConnect、EasyTier、Tailscale、ZeroTier、MASQUE）。
- **许可证**：自有代码采用 `GPL-3.0-only`（见根 `LICENSE`），第三方材料保留各自原版权与许可证。

## English

`v1.0.0` is a **source-first release** published prior to full-tree verification (`v1.0.0`, commit `57f036c646d85ff71d78ba10aca8af52d1b7326c`). The initial release provides source code only; binaries will be attached once corresponding builds complete on dedicated workers, and subsequent code fixes will be released as new patch versions.

### Included in This Snapshot

- **23 Protocol Modules**: Includes the 21 existing protocol crates plus newly written native `protocol-tor` (TCP outbound) and `protocol-wireguard` (client/server TCP & UDP).
- **Shared Outbound Dispatcher & Config v2**: Implements the global `EgressRuntime` / `Dispatcher`, per-node family modes (`ipv4-only`, `ipv6-only`, `dual-stack`), remote target pass-through, management accounts (`AccountSpec`), and in-memory payload accounting (`Telemetry`) under configuration schema v2 (see [Configuration v2 Migration](../config-v2-migration.en.md)).

### Known Gaps & Remaining Work

- **Pending Verification**: Full-tree checks, release builds, and test suites for the `v1.0.0` snapshot are currently running on overseas workers; `protocol-wireguard` has not yet been compiled or tested; one SSR IPv6 interoperability case (`auth_aes128_md5 + random_head`) and 18 Sudoku matrix cases remain to be fixed.
- **Unimplemented Features**: Automatic device-level CF WARP provisioning, persistent usage/bandwidth/access history storage, full CLI localization, and six additional tunnel/overlay endpoints (OpenVPN, OpenConnect, EasyTier, Tailscale, ZeroTier, MASQUE).
- **License**: Original code is licensed under `GPL-3.0-only`; third-party materials retain their original licenses.
