# 1.0.1 发行说明

`v1.0.1` 是第一个带 Linux `x86_64` 二进制的版本。

## 变更

- 统计历史：SQLite 用量、带宽和访问记录，`kerlico history` 只读查询。
- 设备所有者库 `kerlico-device`（同进程 WARP）。此版本的 CLI 尚未接入。
- CLI 帮助、参数错误和运行诊断支持 `--lang zh-CN` / `--lang en`。
- H3、TrustTunnel、ShadowTLS、ShadowsocksR、Sudoku、Tor、WireGuard 的协议修订。
- 全工作区 Clippy 清零；Tor 测试夹具不再依赖 umask。

## 产物

- `kerlico`：Linux `x86_64` 二进制。
- `THIRD_PARTY_NOTICES.txt`：实际链接依赖的许可通知。
- `SHA256SUMS`：以上两个文件的校验和。

对应源码就是本标签；构建基线为 Rust `1.99.1`，构建方式见 [README](../../README.md)。已知互通差异见 [STATUS.md](../../STATUS.md)。

## English

`v1.0.1` is the first release with a Linux `x86_64` binary.

- Telemetry history: SQLite usage, bandwidth and access records, plus the read-only `kerlico history` command.
- Device owner library `kerlico-device` (in-process WARP). The CLI does not use it yet in this release.
- CLI help, argument errors and runtime diagnostics support `--lang zh-CN` and `--lang en`.
- Protocol fixes for H3, TrustTunnel, ShadowTLS, ShadowsocksR, Sudoku, Tor and WireGuard.
- Clippy is clean across the workspace; the Tor test fixture no longer depends on the umask.

Artifacts: `kerlico`, `THIRD_PARTY_NOTICES.txt`, `SHA256SUMS`. The matching source is this tag, built with Rust `1.99.1`.
