# 1.3.0 发行说明

新增 6 个隧道与覆盖网络出站，全部用原生 Rust 实现，不启动外部进程。协议模块增至 30 个。

## 新增

| 出站 | 范围 | 真实对端 |
| --- | --- | --- |
| [`masque`](../interfaces/masque.md) | HTTP/3 CONNECT-IP | Xray 26.10.29 |
| [`openvpn`](../interfaces/openvpn.md) | UDP/TCP，证书与用户名密码，`tls-auth`、`tls-crypt`，AEAD，换钥 | OpenVPN 2.6.20、2.4.12 |
| [`openconnect`](../interfaces/openconnect.md) | 用户名密码，TLS 上的 CSTP，DPD | ocserv 1.1.6 |
| [`tailscale`](../interfaces/tailscale.md) | pre-auth key，DERP、直连、出口节点 | headscale 0.27.1，tailscale 1.92.3 |
| [`easytier`](../interfaces/easytier.md) | 网络名与密钥，TCP/UDP 对端，子网代理 | easytier-core 2.6.4 |
| [`zerotier`](../interfaces/zerotier.md) | 私有网络，配置的根或对端 | zerotier-one 1.14.2 |

- **VLESS**：XUDP 跨载体迁移。混合 NFS 密钥链与 ML-DSA-65 校验此前已可用，这次补上对真实 Xray 的验证。

## 修复

发布前做了独立代码审查，修复了以下问题。其中涉及 1.2.0 的部分建议升级。

- **VLESS Mux UDP**：单个目标队列满时结束整个会话，现在只丢弃该包。
- **TUN**：单次写失败不再结束节点；接受已配置地址族内任意来源，可作网关；新增 `max_flows`，默认 1024。
- **入口失败不再静默**：立即向标准错误打印诊断，`/v1/health` 转为 `degraded` 并列出标签。
- **文件描述符耗尽**：EMFILE、ENFILE、ECONNABORTED 不再让监听入口永久停止。
- **控制接口**：最多 64 条连接，单连接总时长 30 秒；`/v1/online` 遮罩来源地址。
- **DNS**：配置 `dns` 后不再读系统 `/etc/hosts`。
- **路由校验**：引用不存在的节点或用户、与 `require_remote_eof` 冲突的规则现在在 `check` 时拒绝。此前拼错的拒绝规则会静默放行。
- **事件历史**：补上空闲超时等此前遗漏的失败，新增 `flow.failed`、`dns.aborted`、`events.dropped`。
- **OpenVPN**：要求服务端证书带 serverAuth EKU；控制通道重放防护改为先验证会话；TCP 发送停滞时能超时重连。
- **Tailscale**：握手和 disco 先校验再做 DH；STUN 事务 ID 随机并校验来源；注册和首个 map 请求有超时。
- **ZeroTier**：未认证流量不再阻断入网和新目标；只从对应请求的 OK 学习路径；工作量证明不再阻塞数据面；身份文件原子写入；旧配置重放不再回退网络配置。
- **OpenConnect、MASQUE**：认证失败按出站退避，避免错误口令被多个来源放大。

## 变化

- `/v1/online` 的 `address` 从完整 IP 改为遮罩后的网段字符串，同网段合并计数。
- `Cargo.lock` 增加约 200 个依赖，二进制增大约 16 MB，主要来自 EasyTier。
- 从源码构建默认特性需要 `protoc`，`tools/fetch_protoc.sh` 可下载固定版本。不需要时关闭 `protocol-easytier`。
- 启用 XUDP 的 VLESS 节点上，每个 XUDP 会话占一个流配额。`max_sessions` 为 1 的节点会拒绝 XUDP。

## 许可

- `third_party/zerotier-node` 翻译自 ZeroTierOne 1.16.2 的 `node/`，按文件保留 MPL-2.0，并通过路径依赖链接。其余自有代码仍为 `GPL-3.0-only`。
- `kerlico-easytier` 依赖上游 EasyTier（LGPL-3.0）。

## 限制

- 各出站只实现客户端，未实现的选项见各接口文档。较常见的有：OpenVPN 不支持 CBC 与压缩（含 `comp-lzo no`）；OpenConnect 只走 TLS，没有 DTLS；ZeroTier 不支持 AES-GMAC-SIV，FIPS 节点或开启加密 HELLO 的 1.16 节点无法互通。
- Tailscale 没有在官方 SaaS 控制面、IPv6 tailnet 地址或真实 NAT 穿透上测试过；直连测试发生在同一 Docker 网桥上。
- ZeroTier 只与 1.14.2 节点互通测试过，没有连过公网 planet。
- MASQUE 不支持 HTTP/2、CONNECT-UDP 和 Cloudflare 配置档；Xray 重启后旧隧道要等 30 秒 QUIC 空闲超时才恢复。
- VLESS 出站没有多目标 UDP 关联，不能作为 TUN 或 SOCKS5 UDP 的出站。

## English

Six tunnel and overlay outbounds, all native Rust with no external processes: `masque`, `openvpn`, `openconnect`, `tailscale`, `easytier` and `zerotier`. Each passed real TCP and UDP traffic against the upstream peer listed above. VLESS gains XUDP migration across carriers, with mixed NFS key chains and ML-DSA-65 verification now verified against real Xray.

Fixed after an independent code review, so upgrading from 1.2.0 is recommended:

- VLESS Mux UDP: a full per-target queue no longer ends the whole session.
- TUN: a single write failure no longer stops the node; any source in a configured family is accepted, so gateway use works; new `max_flows` option, default 1024.
- A failed inbound now prints a diagnostic at once and turns `/v1/health` to `degraded`.
- EMFILE, ENFILE and ECONNABORTED no longer stop a listener for good.
- Control interface: at most 64 connections, 30 s per connection, and `/v1/online` masks addresses.
- DNS: with `dns` configured, the system `/etc/hosts` is no longer read.
- Route validation: rules naming unknown nodes or users, or conflicting with `require_remote_eof`, now fail at `check`. A misspelled block rule used to fail open.
- Event history: covers idle timeouts and other failures it missed.
- OpenVPN: requires the serverAuth EKU, validates the session before replay state changes, and recovers from a stalled TCP send.
- Tailscale: checks before DH on handshakes and disco; randomized and source-checked STUN; timeouts on register and first map.
- ZeroTier: unauthenticated traffic no longer blocks joining; paths are learned only from matching OK replies; proof of work no longer blocks the data plane; atomic identity writes; replayed older configs no longer roll the network back.
- OpenConnect and MASQUE: login failures back off per outbound.

Changes: about 200 more dependencies and about 16 MB more binary size, mainly from EasyTier. Building default features from source needs `protoc` (`tools/fetch_protoc.sh`), or turn off `protocol-easytier`. Each XUDP session on a VLESS node takes a stream quota slot.

Licensing: `third_party/zerotier-node` is translated from ZeroTierOne 1.16.2 `node/` and stays MPL-2.0 per file. Original code stays `GPL-3.0-only`. `kerlico-easytier` depends on upstream EasyTier (LGPL-3.0).

Limits: client roles only; see each interface document. OpenVPN has no CBC or compression, including `comp-lzo no`. OpenConnect runs over TLS only. ZeroTier has no AES-GMAC-SIV, so FIPS peers and 1.16 peers with encrypted HELLO cannot interoperate. Tailscale was not tested against the official SaaS control plane or real NAT traversal. ZeroTier was only tested against 1.14.2 nodes. The VLESS outbound has no multi-target UDP association, so it cannot serve TUN or SOCKS5 UDP.
