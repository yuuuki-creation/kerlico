# 1.14.0 发行说明

M12–M13 Mihomo 替换就绪与真实化收口版本。完成 M11 审计列出的 DNS 管线、Geo 与二进制规则集（`.srs`/`.mrs`）运行时加载、Linux TUN 自动路由与防回环、全协议 `DialerOptions` 拨号工厂、`sing-mux`（`smux`/`yamux`/`h2mux`）与上游线格式互通、uTLS ClientHello 指纹与完整套件通告、Hysteria2 带宽协商与 Brutal 拥塞控制、控制面 WebSocket 实时推送与 `PATCH /configs`，并通过同配置 Mihomo v1.19.33 对照验收（14 场景与 600 秒混合流量长稳 34,632 请求 0 失败）。详见 [Mihomo 替换验收报告](../testing/mihomo-replacement-acceptance-2026-11-07.md)。

## 新增与真实化能力

- **统一 DNS 管线与 IP 规则解析**：本地出网、劫持 DNS、`dns.listen` 与 `/dns/query` 共用同一解析管线；按 `hosts` → Fake-IP（含 `fake-ip-filter`） → `nameserver-policy` → `nameserver` / `fallback`（含 `fallback-filter`）求值，支持 UDP、TCP、DoT、DoH 与 `default-nameserver` 引导解析。路由含 IP/GeoIP/ASN 规则且未标 `no-resolve` 时，对域名目标先解析再匹配 IP 规则。
- **运行时 Geo 数据与 `.srs`/`.mrs` 规则集**：运行时直接读取 MetaCubeX / sing-box 真实 `geoip.dat`、`geosite.dat`、`country.mmdb`、`ASN.mmdb`（兼容 `GeoLite2-ASN.mmdb`）及二进制 `.srs`（v1–v4）、`.mrs`（v1 domain/ipcidr）规则集；`GEOIP,private` 查 Geo 库，`lan` 使用内置私网判定；CLI `rule-set` 与 `geoip`/`geosite` 子命令操作真实格式。
- **Linux TUN 自动路由与防回环**：按 `sing-tun` 布局安装独立路由表与策略规则，支持 IPv4/IPv6 默认路由、`strict-route`、`auto-redirect`（nftables）、`auto-detect-interface` 与逐出站 `routing-mark` 防回环放行规则；未写 `inet4-address` 时沿用 Mihomo 默认 `198.18.0.1/30` 与 `fdfe:dcba:9876::1/126`，Fake-IP 从 `.4` 起分配。
- **全局拨号选项与 TLS/uTLS 指纹**：全部出站协议与 DNS 上游套接字统一经 `DialerOptions` 工厂创建，覆盖 `interface_name`、`routing_mark`、`tcp_fast_open`、`tcp_multi_path`、`bind_address` 与 `detour`/`dialer-proxy`；全部 TLS 载体支持 `skip-cert-verify`；Mihomo `client-fingerprint` 映射为 uTLS ClientHello 指纹，通告档案完整密码套件（含遗留套件槽位与 GREASE），并在服务端非法选中遗留套件时终止握手；TLS 1.2 时代档案省略 `supported_versions`。
- **`sing-mux` 线格式互通与 SS2022 复用**：`h2mux`、`smux`（v1/v2）、`yamux` 及 padding 帧头与 `sagernet/sing-mux`、Mihomo 双向互通；SS2022 出站与入站支持 `sing-mux`。
- **入站嗅探与透明代理**：调度器内置统一嗅探阶段，覆盖 TLS SNI、HTTP Host、QUIC 多包重组、BitTorrent、DTLS、STUN、SSH、RDP；支持 Mihomo `sniffer` 的 `force-domain`、`skip-domain`、`skip-src-address`、`skip-dst-address`（含 `geoip:`、`geosite:`、`rule-set:` 条目）。TProxy UDP 按 `IP_RECVORIGDSTADDR` / `IPV6_RECVORIGDSTADDR` 提取原始目标并支持 IPv6 與 `lan-disallowed-ips` 来源拦截；`bind-address: "*"` 启用双栈监听。
- **Hysteria2 带宽、Brutal 与伪装代理**：实现 `Hysteria-CC-RX` 双向带宽协商、每连接 Quinn Brutal 拥塞控制器与 `ignore_client_bandwidth`；`masquerade` 的 `proxy` 支持真实 HTTP/HTTPS 反向代理、`rewrite_host` 与 `insecure`；客户端首包随流头一并发出。
- **控制面 WebSocket、日志管线与 Mihomo 兼容细节**：新增 `/traffic`、`/memory`、`/logs`、`/connections` WebSocket 实时推送与进程级日志管线（级别过滤、文件输出、时间戳）；实现 `PATCH /configs`（改 `mode`、`log-level` 就地生效，改监听或 `tun` 重建引擎）与 `rule`/`global`/`direct` 运行模式切换；`/rules` 返回逐规则 `hitCount`/`hitAt`/`missCount`/`missAt`；控制接口路径先百分号解码；出站与策略组名称保留中文、emoji、空格与括号，`filter` 支持完整正则（含负向前瞻与反引号多表达式），订阅 `override` 先于字段映射执行。
- **TUN 高并发长稳与内存优化**：规则求值惰性反查本机进程；TUN 劫持的 DNS 在关联首包就地应答，不再泄漏空闲出站 UDP 套接字；TUN 设备读取独立为单独任务，入站 SYN 与监听 socket 原子入队；用户态 TCP 每向缓冲由 1 MiB 降为 256 KiB，默认全局会话上限调至 4,096 并在流表满时优先回收已关闭 TCP 与最久未用 UDP。

## English

M12–M13 Mihomo drop-in replacement and verification release. Completes the remaining M11 audit units across DNS, runtime Geo and binary rule-sets (`.srs`/`.mrs`), Linux TUN routing and loop prevention, universal `DialerOptions` socket factory, wire-compatible `sing-mux` (`smux`/`yamux`/`h2mux`), uTLS ClientHello fingerprinting with full cipher advertisement, Hysteria2 Brutal congestion control and masquerade reverse proxy, control-plane WebSocket streams and `PATCH /configs`. Verified against Mihomo v1.19.33 on the same configuration across 14 scenarios and a 600-second mixed-traffic soak (34,632 requests, 0 failures); see [the Mihomo replacement acceptance report](../testing/mihomo-replacement-acceptance-2026-11-07.md).

- **Unified DNS & IP-rule resolution.** Local egress, hijacked DNS, `dns.listen` and `/dns/query` share one pipeline (`hosts` → Fake-IP with `fake-ip-filter` → `nameserver-policy` → `nameserver` / `fallback` with `fallback-filter`) over UDP, TCP, DoT and DoH, resolving domain targets when IP/GeoIP/ASN rules require it.
- **Runtime Geo & `.srs`/`.mrs` rule-sets.** Loads real `geoip.dat`, `geosite.dat`, `country.mmdb`, `ASN.mmdb` (`GeoLite2-ASN.mmdb` fallback), `.srs` (v1–v4) and `.mrs` (v1) files at runtime and in CLI subcommands.
- **Linux TUN automation & soak stability.** `sing-tun`-aligned policy routing (`auto-route`, `strict-route`, `auto-redirect`, `auto-detect-interface`, per-outbound `routing-mark` bypass, IPv6 routes, Mihomo default `198.18.0.1/30` and `fdfe:dcba:9876::1/126` addresses). Dedicated TUN reader task, atomic SYN + listener enqueue, in-place hijacked DNS replies, lazy process lookup and 256 KiB per-direction TCP buffers cut soak peak FDs from 915 to 28 and average RSS from 325 MiB to 179.5 MiB with zero packet drops.
- **Dialer factory, uTLS & `sing-mux`.** All outbounds and DNS upstreams route through `DialerOptions` and support `skip-cert-verify` and uTLS `client-fingerprint` (including full legacy cipher advertisement for Chrome/Firefox JA3/JA4 parity and TLS 1.2 profile `supported_versions` omission). `sing-mux` (`h2mux`/`smux`/`yamux` + padding) interoperates bidirectionally with `sagernet/sing-mux` and Mihomo, including over SS2022.
- **Control plane, Hysteria2 & sniffing.** WebSocket streams for `/traffic`, `/memory`, `/logs`, `/connections`; `PATCH /configs`; `rule`/`global`/`direct` modes; per-rule hit counters on `/rules`; Hysteria2 `Hysteria-CC-RX` bandwidth negotiation, Quinn Brutal controller and HTTP/HTTPS masquerade proxy; unified dispatcher sniffing (TLS, HTTP, multi-packet QUIC, BitTorrent, DTLS, STUN, SSH, RDP) with `geoip:`/`geosite:`/`rule-set:` skip lists; TProxy UDP original destination recovery (`IP_RECVORIGDSTADDR`/`IPV6_RECVORIGDSTADDR`).
