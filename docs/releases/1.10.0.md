# 1.10.0 发行说明

完成 `M0`（`v1.3.3`）至 `M7`（`v1.10.0`）三核心（Mihomo、sing-box、Xray）主要功能对齐，能力总表实测通过项由 1,180 项提升至 2,080 项（已实现 1,621 项、部分实现 459 项，未测 0 项），默认构建中的双端协议由 20 个扩充至 22 个（新增 MASQUE 与 OpenVPN 服务端入站）。

## 新增与增强

- **入站与隧道双端闭环（`M1`、`M7`）**：新增 `mixed`（HTTP+SOCKS 首字节自动识别）、`redirect`、`tproxy` 系统入站，新增 `masque` 与 `openvpn` 服务端入站（TLS 1.3 控制通道、`key_method_2`、`PUSH_REPLY`、`tls-auth`/`tls-crypt`/`tls-crypt-v2`、AEAD `DataV2` 与 `ServerTunnel` 用户态 IP 栈转发），支持 Trojan/VLESS 入站 `fallback` 分流（含 `xver` PROXY v1/v2）与 `dns` 内部出站。
- **传输、安全、多路复用与链式拨号（`M2`）**：新增 `dialer-proxy` / `detour` 链式代理拨号、入站 `accept_proxy_protocol`（PROXY v1/v2）、`sing-mux`（`h2mux`/`smux`/`yamux` 及 padding）、Shadowsocks `UoT` v1/v2、XHTTP 分帧/混淆/`xmux`、Xray `finalmask`（`fragment`/`udp_hop`/`brutal`）、TLS 证书/公钥 SHA-256 固定、ECH、证书热重载、内置 ACME 自动签发与 REALITY `mldsa65_seed`。
- **流量嗅探、DNS/Fake-IP、规则集与 TUN 自动化（`M3`）**：新增 TLS SNI / HTTP Host / QUIC Initial / BitTorrent / SSH / RDP 协议嗅探，新增双栈 Fake-IP 地址池（`198.18.0.0/15`、`fc00::/18`）与磁盘持久化还原，支持 DoH/DoQ、乐观缓存、ECS、`.srs`/`.mrs` 二进制规则集、逻辑规则（`and`/`or`）及 TUN `auto-route`/`auto-redirect`/`strict-route`。
- **策略组、订阅提供者、控制面 API、Web 面板与 CLI 工具链（`M4`、`M5`）**：新增 `select`/`url-test`/`fallback`/`load-balance`/`balancer` 策略组与 `proxy-providers` 订阅解析，支持 JSONC/YAML/TOML 配置、`-C` 多配置文件深度合并与环境变量覆写，扩展 Clash/Mihomo/Xray/SSM 控制面 API 与 `/ui` 静态 Web 面板托管，新增 `format`/`merge`/`rule-set`/`geoip`/`geosite`/`generate`/`tls`/`xray`/`tools` CLI 子命令。
- **内置 NTP、Shadowsocks SIP003 与 VLESS Reverse（`M6`）**：内置 SNTP/NTPv4 时钟偏移校准客户端（支持经代理出站拨号），支持 Shadowsocks SIP003 子进程托管与 `obfs-local`/`v2ray-plugin` 原生兼容，新增 VLESS Reverse 内网穿透反向代理（Portal <-> Bridge 隧道派发）。

## English

Completes stages `M0` (`v1.3.3`) through `M7` (`v1.10.0`) aligning the core capabilities of Mihomo, sing-box, and Xray. Verified capability matrix items increased from 1,180 to 2,080 (1,621 implemented, 459 partial, 0 untested), and dual-ended protocols in the default build expanded from 20 to 22 (`masque` and `openvpn` server inbounds).

- **Inbounds and dual-ended tunnels (`M1`, `M7`).** Added `mixed`, `redirect`, and `tproxy` inbounds, `masque` and `openvpn` server inbounds (TLS 1.3 control channel, `key_method_2`, `PUSH_REPLY`, `tls-auth`/`tls-crypt`/`tls-crypt-v2`, AEAD `DataV2`, and `ServerTunnel` user-space IP forwarding), Trojan/VLESS inbound `fallback` (with `xver` PROXY v1/v2), and the internal `dns` outbound.
- **Transport, security, multiplexing, and dialer chaining (`M2`).** Added `dialer-proxy` / `detour` chaining, inbound `accept_proxy_protocol` (PROXY v1/v2), `sing-mux` (`h2mux`/`smux`/`yamux` with padding), Shadowsocks `UoT` v1/v2, XHTTP framing/obfuscation/`xmux`, Xray `finalmask` (`fragment`/`udp_hop`/`brutal`), TLS certificate/SPKI SHA-256 pinning, ECH, hot reload, built-in ACME provisioning, and REALITY `mldsa65_seed`.
- **Protocol sniffing, DNS/Fake-IP, rule-sets, and TUN automation (`M3`).** Added TLS SNI / HTTP Host / QUIC Initial / BitTorrent / SSH / RDP sniffing, dual-stack Fake-IP pools (`198.18.0.0/15`, `fc00::/18`) with disk persistence, DoH/DoQ, optimistic cache, ECS, `.srs`/`.mrs` binary rule-sets, boolean rules (`and`/`or`), and TUN `auto-route`/`auto-redirect`/`strict-route`.
- **Proxy groups, providers, Control API, Web UI, and CLI toolchain (`M4`, `M5`).** Added `select`/`url-test`/`fallback`/`load-balance`/`balancer` groups and `proxy-providers`, JSONC/YAML/TOML configs, `-C` multi-file deep merge and environment variable overrides, Clash/Mihomo/Xray/SSM Control APIs and `/ui` static Web UI hosting, plus `format`/`merge`/`rule-set`/`geoip`/`geosite`/`generate`/`tls`/`xray`/`tools` CLI subcommands.
- **Built-in NTP, Shadowsocks SIP003, and VLESS Reverse (`M6`).** Added a built-in SNTP/NTPv4 client (supporting proxy dialers), Shadowsocks SIP003 plugin process management and native `obfs-local`/`v2ray-plugin` compatibility, and VLESS Reverse portal/bridge tunnel dispatch.
