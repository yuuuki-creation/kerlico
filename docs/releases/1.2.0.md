# 1.2.0 发行说明

## 新增

- **TUN 入站**：节点类型 `tun`，把内核 IP 包还原成业务流进入共享调度器。kerlico 不修改系统路由，见 [TUN 入站](../interfaces/tun.md)。
- **DNS 模块**：`dns` 段配置 UDP、TCP、TLS 上游和静态 hosts，供 `Local` 路径解析网站域名，见 [DNS](../interfaces/dns.md)。
- **控制接口**：`control` 段开启只读 HTTP 接口，查询健康状态、用量、在线来源、访问记录和入口计数，见[控制接口](../interfaces/control.md)。
- **`direct` 绑定接口**：`"options": {"interface": "eth0"}`，配合 TUN 避免回环。

## 修复

- **SS2022 出站偶发被拒**：上游 `shadowsocks` 1.25.0 为无负载首包取 `0..=900` 的随机填充，取到 0 时服务端拒绝。kerlico 的 SS2022 出站每条连接都先空写首部，所以每条连接有约 0.11% 的概率失败。此前所有版本都受影响。现在纳入 `third_party/shadowsocks` 并改为 `1..=900`。

## 限制

- TUN 看到的目标都是 IP，域名规则不命中；暂无 Fake-IP 或首包嗅探。
- TUN 的 UDP 固定走节点绑定的出站。
- TUN 只在 Linux 验证过。

## English

- **TUN inbound**: the `tun` node type turns kernel IP packets into flows through the shared dispatcher. kerlico does not change system routes.
- **DNS module**: `dns` configures UDP, TCP and TLS upstreams plus static hosts for the `Local` path.
- **Control interface**: `control` enables a read-only HTTP API for health, usage, online sources, flow records and counters.
- **`direct` interface binding**: `"options": {"interface": "eth0"}` prevents routing loops with TUN.

Fixed: SS2022 outbound connections failed about 0.11% of the time, because upstream `shadowsocks` 1.25.0 picks padding from `0..=900` for an empty first packet and its server rejects zero. All earlier versions are affected. The patched crate now lives in `third_party/shadowsocks`.

Limits: TUN sees IP targets only, so domain rules do not match, and there is no Fake-IP or sniffing yet. TUN UDP always uses the node's outbound. TUN has only been verified on Linux.
